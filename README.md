## Deskripsi Program

### 1. Sistem Pengelolaan Inventaris Laboratorium
Program ini digunakan untuk mengelola data barang laboratorium komputer, seperti menampilkan, menambahkan, mencari, dan menghapus barang.

Function yang digunakan:
- tampilkanBarang(): Menampilkan daftar barang.
- tambahBarang(): Menambahkan barang baru.
- cariBarang(): Mencari barang.
- hapusBarang(): Menghapus barang.

### 2. Pengolahan Nilai Praktik Siswa
Program ini digunakan untuk menampilkan nilai siswa, menghitung rata-rata, dan menentukan jumlah siswa yang tuntas maupun belum tuntas.

Function yang digunakan:
- tampilkanNilai(): Menampilkan nilai siswa.
- hitungRataRata(): Menghitung nilai rata-rata.
- hitungJumlahTuntas(): Menghitung jumlah siswa yang tuntas.

## Cara Menjalankan Program

1. Pastikan Node.js sudah terinstal.
2. Buka folder tugas melalui VS Code.
3. Buka Terminal.
4. Jalankan perintah berikut:

node 01-inventaris-lab.js

Untuk menjalankan program kedua:

node 02-pengolahan-nilai.js
